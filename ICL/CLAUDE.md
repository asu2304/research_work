## 1. The task (all folders share this)
In-context learning of a **Markov chain corrupted with noise**. Each sequence has its OWN
random transition table; the model must infer it from context and predict the next token.

- Vocab `V=20`: **signal** tokens `0–9` (`V_sig=10`), **noise** tokens `10–19` (`n_noise=10`). `seq_len=200`.
- Each signal state has **exactly 2 equiprobable successors** (the "toy" structure — important: this
  sparsity is what makes a nonlinear/FFN readout helpful; see §2/§5).
- Generation with threshold **α**: at each step, w.p. α emit a successor of the current state
  (α/2 each) and update state; w.p. (1−α) emit a uniform **noise** token (state unchanged).
- Loss / eval on the **last suffix_len=100 tokens** (window `TOKEN_START=100 : TOKEN_END=200`).
- Thresholds studied: α ∈ {0.1, …, 0.9}. Bayes argmax is a successor for α≥0.2 (=α/2); noise for α=0.1.

**Dataset** (one copy, reused by every folder via absolute path):
`6. understanding what gradient descent is firuring out/dataset/{train,test}/data_x_{α}.pt`
(train 20k / test 3k seqs). Generated by `data_generation.py` (seed 42 + idx·1000 per α).
α=0.8 was **regenerated** with seed 80808/80809 (old copy kept as `data_x_0.8.pt.bak_outlier`;
both are statistically identical — the regen did NOT fix anything, see §2).

## 2. Predictor hierarchy (the mental model for every CE plot)
For a context-only predictor, CE (lower = better) orders as:
```
ideal-α  ≤  context-Bayes  ≤  ctx-count  ≤  no-FFN W*(softmax)
(knows       (best from        (normalized    (W* logits re-exponentiated
 true table)  context)          empirical      by softmax -> slightly worse)
                                 counts)
```
- **ideal-α**: knows the true 2-successor table → α/2 on each true successor, (1−α)/n_noise on noise. The floor.
- **ctx-count** (`alpha_ce`): empirical successor counts of the current state, smoothed, ×α, + exact noise floor. = what a perfect induction head outputs.
- **context-Bayes**: posterior-predictive given the observed counts + the 2-equiprobable prior
  (equalize the 2 observed successors to α/2, exact noise floor). ≈0.04 nats below ctx-count at high α;
  ≈ctx-count at low α. Verified e.g. α=0.8: ctx 1.575 / Bayes 1.533 / ideal 1.518.
- **The induction attention already computes ctx-count** (averaging successor one-hots = empirical
  freq). A plain softmax readout distorts it; the FFN's job is to undo that (log → recover counts)
  and optionally equalize toward context-Bayes.

**Key theory results we established:**
- The α=0.8 softmax non-convergence is a **noise-density phase transition** (the hard sub-task is
  predicting AFTER a noise token — recover state from the last signal). Post-noise wrong-successor rate
  is ~0.3% for α≤0.7 but ~50% for α≥0.8. NOT a data/seed/width problem (all ruled out empirically).
- **Infinite context ⇒ FFN gives ZERO gain**: counts → true table (LLN), ctx-count → Bayes → ideal.
  The FFN's entire value is **finite-sample** count-denoising; it decays ~O(1/n).
- **Unstructured full Markov (Dirichlet rows) ⇒ FFN can't beat ctx-count**: ctx-count = add-β smoothing
  = Bayes posterior (Dirichlet-multinomial conjugacy). FFN gain exists ONLY when the prior has
  structure (sparsity / heterogeneity). The toy 2-successor case is the extreme structured example.
- An FFN **can always match ctx-count** (it's a universal normalize — the same fn for every context);
  what it can't do in general is reach ideal-α (needs the unobservable true table).

## 3. Models / architectures
All use the "DisentangledTransformer": one-hot token ⊕ one-hot position → 2 **ConcatAttentionBlocks**
(each: `s' = cat[s, attn_out]`, causal) → `fc_out` (unembedding, bias) → softmax. `attn_dim=220`,
`initial_dim = V+seq_len = 220`; layer dims 220 → 440 → 660 → V.

| name | attention | extra | folder / script → checkpoint |
|---|---|---|---|
| **gd** (softmax) | separate Wq,Wk,Wv,Wo | none | 6 `train.py` → `model_x_{α}.pth` |
| **gd_comb** | combined **W_qk=WqᵀWk, W_ov=WoWv** | none | 7 `train_combined.py` → `model_x_{α}.pth` |
| **mlp** (minimal MLP) | separate | +1 residual FFN (660→128→660, GELU) before fc_out | 6 `train_with_mlp.py` → `model_mlp_x_{α}.pth` |
| **twocell** | separate | FFN after BOTH layers (2 full transformer cells); optional LayerNorm toggles | 8 `train_two_cell.py` → `model_mlp_x_{α}.pth` |
| **twocell_comb** | combined W_qk,W_ov | FFN after both layers | 8 `train_two_cell_combined.py` → `model_mlp_comb_x_{α}.pth` |
| **freeze** | separate, layer-2 V/O+fc_out pinned to W* | learnable noise-floor bias only | 6 `train.py` head='freeze_readout' → `model_freeze_readout_x_{α}.pth` |
| **W\*** (`PerfectInductionTransformer`) | hand-coded perfect induction circuit | temperature σ applied at readout | defined inside the analysis notebooks |

QK/OV decomposition (folder 7): attention only uses Wq,Wk via `WqᵀWk` and Wv,Wo via `WoWv`, so the
combined parametrization is exact; collapsing W* into W_qk/W_ov gives identical logits (verified 0.0 diff).

## 5. `8/analyse.ipynb` — the current main deliverable
Single self-contained notebook (rewritten from a 2-cell version that wasted compute). Cells:

1. **`merged-analyse`** — settings + all model/W*/baseline definitions + **lazy** CE evaluation + plot,
   all in one cell. Computes **only the curves toggled `True` in `SHOW`** and **only for the chosen
   `SPLIT`** (no more "run the expensive settings cell, lose it on disconnect"). Discovers α from the
   dataset. Curve keys: `ideal, ctx, gd, gd_comb, mlp, twocell, twocell_comb, wstar, wbetter, l1, freeze,
   ffn_log1/2, ffn_relu_log, ffn_gelu_log`. W* is built ONCE (cached). Pulls trained models from
   folders 6/7/8 by absolute path. Saves `models/ce_all_{SPLIT}.png`.
   - **`FFN_FLOORS`** (hardcoded): log-readout floors `(b_sig,b_noise)` per α/split, **grid-searched
     once** (`_find_floors.py` → `_floors.json`) so the cell never re-searches. Re-tune via that script.
2. **`equalize-construction`** — the hand **GELU "equalize" FFN** that **matches the GD minimal-MLP**.
   Levels set analytically from α (= context-Bayes target): signal coord → GELU soft-step on the W*
   count/freq (observed successor → `log(α/2)`, unobserved signal → a tuned `OFF` floor); noise coord →
   exact `log((1−α)/n_noise)`. GELU with input gain g=200 ≈ a ReLU hard step.
   - **`EQ_PARAMS`** (hardcoded `(tau,w,off)` per α): grid-searched once (`_find_match.py` → `_match.json`).
   - Result (test): closes the old log-readout gap and tracks GD MLP within ±0.015 nats, BEATING it at
     α∈{0.1,0.3,0.8}. e.g. α=0.8 eq **1.5674** vs mlp **1.5692** (old log readout was 1.5955);
     α=0.9 eq 1.2203 vs mlp 1.2157. It does NOT reach ideal-α (would need n_obs-aware routing a single
     position-wise FFN can't do exactly).

**Why the gap existed / was closed:** the GD minimal-MLP is essentially AT ctx-count; the old
`ffn_gelu_log` construction ran `log()` on the NOISE coords too (noisy empirical noise freqs) instead of
pinning the exact floor, so it sat above. The equalize construction fixes the noise floor + equalizes signal.

**Hardcoding convention (important to the user):** any grid search is run ONCE offline, the argmin is
hardcoded with a comment naming the search grid, and the cell just evaluates at the optimum — never
re-search on every run. Provenance scripts to KEEP in folder 8: `_find_floors.py`+`_floors.json`,
`_find_match.py`+`_match.json`. Other `_*.py` there (`_close_gap*`, `_inarch_best`, `_verify_count_readout`)
are the user's own experiments.
